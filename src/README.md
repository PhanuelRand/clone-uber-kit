# Votre code

C'est ici que vous construisez votre clone d'Uber. Le dossier est
volontairement vide : c'est votre travail.

Les suites de vérification importent votre code à des chemins précis, indiqués
en tête de chaque fichier de `academie/checks/`. Par exemple, le module 1
attend `src/domain/ride.ts` exportant une classe `Ride`.

Au premier push, les huit vérifications sont rouges. C'est normal : vous les
faites passer au vert une par une, module après module.

Pour voir où vous en êtes, sans attendre l'intégration continue :

```bash
npm install
npm run academie 1
```
